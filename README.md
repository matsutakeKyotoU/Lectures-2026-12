# Lectures-2026-12 Sample Data Analysis with ChatGPT

今や生成AIは単にプロンプトを入力してプログラムを書かせるだけの存在ではなくなりました。ChatGPTの**データ分析 Data Analysis**は、自然言語で会話しながら、データを読み込み、内部でプログラムを生成、統計分析、数値計算、グラフ作成、さらには高度な数理モデルの構築まで行える機能です。ここに掲載したのは、講師がChatGPTと会話しながら行なったデータ分析の記録です。

- 昨年の講義では、講師がChatGPTにプロンプトを与えてPythonプログラムを書かせ、それをJupyter Notebookで実行するデモを行いました。いわゆるVibe Codingです。生成されたプログラムには不具合（バグ）がしばしばあり、不具合の修正（デバッグ）も対話セッションで行う必要がありました。しかし、ChatGPTの内部モデルの進化や学習はどんどん加速しており、現在ではプログラムの生成がボトルネックになることはほぼなくなっています。そのため、今年の講義ではプログラムは表面には出て来ず、専らデータの分析と可視化、結果の評価などが対話の中心となります。

- もちろんプログラムの品質はやはり人がチェックすることは必要です。講義の準備にあたり、講師は内部生成されたプログラムをたびたびチェックしましたが、問題点はゼロでした。もちろん講師が気づかない落とし穴がある可能性は排除できませんが、このサンプルレベルの分析であれば、生成プログラムの品質は担保されたものと考えていいと思います。

- 分析結果や評価についても、講師はできる限りチェックしていますが、その正確性を必ずしも保証するものではありません。とは言え、ChatGPTの分析能力はかなりのものだというのが講師の感想です。


## サンプルの実行方法

サンプルには、行なった分析セッションが**htmlフォーマット**で記録されています。用いたデータや出力したグラフなども一緒に保存されており、講師が行なった通りにそれぞれの分析をリプレイできるようになっています。

- リプレイしたいファイルをダウンロードします。（ファイル自体はサイズが大きいため、このGitHubの画面内では開けません。）
    - ファイル一覧（ファイルツリー）からダウンロードしたいファイル名をクリックし、内容をファイルビューに表示させます。（「ファイルサイズが大きすぎて内容が表示されない」というようなメッセージが表示されて内容は見えません。）
    - ファイルビューの中にあるツールバーにダウンロードのアイコンがあります。それをクリックするとダウンロードが開始されます。
    - 自分のダウンロード・フォルダーを確認し、希望ファイルがダウンロードされているかどうか確認してください。
- ダウンロードしたファイルをクリックするなどして、ブラウザの中で開いてください。**Chat Replay Studio**という画面が開き、**▷再生** のボタンが見えます。
- 再生ボタンを押すごとに、講師とChatGPTの会話が、質問と回答のまとまりごとに、一つ一つ再生されます。
    - **注意**  全てのブラウザでの互換性はチェックしていません。なんらかの理由でブラウザ内で実行できない場合には、川北先生を通じて講師にご一報ください。
- 会話の中で表示されるグラフでインタラクティブなものは、リンクとその横に**プレビュー**ボタンが表示されます。プレビューで画面中にグラフが展開しますので、マウスを使って操作することで動的にグラフを動かすことができます。
- なお、掲載した分析セッションは過去の記録であるため、使ったデータは全てその時点でのものであることに留意してください。

## 自分でデータ分析機能を使いたい時

- 講師のサンプルセッションを参考に、同じようなプロンプトを与え、ChatGPTにデータ分析を実行させることができます。
- その場合に、データ取得に問題が発生する可能性があります。
    - ChatGPTには **Chatモード**と**Workモード**があり、ChatモードのPython処理系からは、Web経由での外部データアクセスは保証されていません。そのため、Chatモードで分析を行うと、最初のデータ取得で問題が発生することがあります。
    - 一方、Workモードには**Cloud Browser**という機能があり、これを通じて外部のデータを取得することが可能です。講師のセッションは全てWorkモードで実行しました。データ分析機能でChatGPTにデータの取得を任せたい場合には、Workモードでの実行を勧めます。
- ChatGPTにデータ取得を任せる代わりに、自分の環境でデータ取得のPythonプログラムを走らせ、取得したデータファイルをChatGPTにロードすることができます。
    - ChatGPTがデータ取得ができなかったと返してきたとき、プロンプトから「データ取得用のプログラムをダウンロード可能にして」と指示し、返されたリンクからPythonプログラム、またはJupyter Notebookプログラムをダウンロード、自らそれを走らせてデータファイルを作ることができます。
        - Python環境やプログラム実行方法については、[Python実行環境について](#Python実行環境について)を参照ください。
    - できたデータファイルは、プロンプト左にある`+`をクリックしてプロンプト内に読み込み、ChatGPTにアップロードすることができます。
    - なお、講師のセッションで生成したPythonプログラムをGithubレポジトリに配置していますので、その中からデータ取得用のプログラムを選んで走らせることも可能です。
- 自分で走らせたPythonプログラムが失敗する場合、エラーメッセージをコピーし、ChatGPTに読み込ませてデバッグします。
    - ChatGPTが修正プログラムを生成しますので、結果が出るまでデバッグを繰り返します。
    - 場合によっては、Pythonやライブラリ・パッケージのバージョンのアップデートが必要になる場合があります。ß

## Pythonについて
Pythonはデータ分析、AIを含め幅広い分野で使われているプログラミング言語です。書いたプログラムをその場ですぐに実行できる「スクリプト言語」の一種で、いろいろな機能を持つ別ライブラリ・パッケージが豊富に存在し、それらを組み合わせて使うことで、いろいろなタスクを柔軟にこなすことができます。ライブラリとしては次が代表的なものです。
- データ分析：pandas, numpy, scipy
- AI：TensorFlow, PyTorch, SciKitLearn
- グラフ表示：matplotlib, plotly
- Web作成：Django, Flask

## Python実行環境について
自分のコンピュータにPython がインストールされていることが前提です。

- Pythonが環境に入っていなければインストール: https://www.python.org
	- バージョンは現在3.xx.xx (Stable Releaseで最もバージョンの高いものを選ぶとよい）
	- データサイエンスのパッケージ Anaconda https://www.anaconda.com でもインストール可
	- インストール後、コマンドプロンプト/ターミナルを立ち上げ、`python`(または`python3`)と入力してpythonが起動すればOK
 
- Pythonと組み合わせて使うライブラリ・パッケージをインストール

	- Pythonをインストールすると、パッケージのインストーラ**pip**が付属しています
	- コマンドプロンプト/ターミナルから`pip install <パッケージ名>`と入力　（パッケージ名は複数指定可能）
		- Jupyter Notebookは`pip install notebook`でインストール可能
        - Pythonの実行時に「パッケージがない」エラーが出た場合には、その都度`pip install <パッケージ名>`でインストールしてプログラムを再実行
    - パッケージのバージョンアップが必要な場合には `pip install --upgrade <パッケージ名>`

 
- Pythonプログラムの実行
    - **.py**という拡張子のファイルはPythonコードです。コマンドプロンプト/ターミナルから次のコマンドで実行できます
        - `python（またはpython3）<ファイル名>.py` 
    - **.ipynb**という拡張子のファイルはJupyter Notebookコードです。Notebookにファイルを読み込んで実行できます 
        - コマンドプロンプト/ターミナルから`jupyter notebook`または`python (またはpython3) -m notebook`と入力
        - ブラウザ内でJupyter Notebookの画面が開く
        - **File**メニューからファイルを選んでロードし、**Run > Run Selected Cell** または **▷ボタン** でセルごとに逐次実行
        - Pythonプログラムをメモリーにコピーし、Notebookセルにペーストして実行することも可能
